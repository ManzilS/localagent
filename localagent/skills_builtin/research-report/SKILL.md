---
name: research-report
description: Research a question on the web and write a sourced report or comparison
---
1. Break the question into 3–6 concrete sub-questions. For product comparisons: price, key specs, reviews, availability, date.
2. For each sub-question: web_search, then web_fetch the 2–3 most authoritative results (official sites, reputable reviews, primary sources). Skip SEO listicles when better sources exist.
3. Note every fact with its URL as you go. If sources disagree, record both and say which is newer or more reliable.
4. Prefer recent information — check the date on each page. Say so when something may have changed.
5. Write the report to a .md file in the workspace: a 2–3 sentence answer first, then a comparison table if there are options, then details, then a Sources list.
6. Reply with the short answer and the file path. Don't paste the whole report into chat.
