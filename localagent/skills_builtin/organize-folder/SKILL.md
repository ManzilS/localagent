---
name: organize-folder
description: Tidy a messy folder (Downloads, Desktop, a project) into sensible subfolders without losing anything
---
1. list_dir the folder (depth 1) and count files by type. If it has more than ~300 items, work in batches.
2. Propose a short plan to yourself: Images, Documents, Spreadsheets, Presentations, Archives, Installers, Audio, Video, Code, Other — only the categories that actually appear. Keep existing subfolders as they are.
3. Duplicates: same name with " (1)", "copy" etc. AND same size → keep the newest, trash_path the others with reason "duplicate of <name>". Never trash anything else.
4. Move files with move_path. Do not rename files unless the user asked.
5. Leave anything modified in the last 24 hours where it is (the user may be working on it) and mention it.
6. Finish with a table: category → number of files moved, plus duplicates moved to the trash (they can be restored from the Trash page).
